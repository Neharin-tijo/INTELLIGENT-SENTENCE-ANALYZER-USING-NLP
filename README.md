# Intelligent Sentence Analyzer Using NLP

## 1. Project description
This application analyzes English text with a pretrained spaCy model. It demonstrates core Computational Linguistics concepts:
- Tokenization
- Lemmatization
- Stemming (Porter and Snowball)
- Part-of-speech (POS) tagging
- Morphological features
- Dependency parsing and dependency-tree visualization
- Named entity recognition
- Sentence and token statistics
- CSV export

## 2. Requirements
- Python 3.10 or 3.11 recommended
- Internet access for the first installation of the spaCy English model
- A modern web browser

## 3. Setup on Windows, macOS, or Linux
Open a terminal in this folder and run:

```bash
python -m venv .venv
```

Activate the environment:

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install dependencies:
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

Start the app:
```bash
streamlit run app.py
```

The terminal will display a local URL (usually http://localhost:8501). Open it in your browser.

## 4. Quick test
Enter:
`The boy eats an apple.`

Expected linguistic analysis (the precise tags can vary by model version):
- `The`: POS=DET, dependency=det, head=`boy`
- `boy`: POS=NOUN, dependency=nsubj, head=`eats`
- `eats`: POS=VERB, dependency=ROOT, head=`eats`
- `an`: POS=DET, dependency=det, head=`apple`
- `apple`: POS=NOUN, dependency=obj, head=`eats`
- `.`: punctuation token

The application also draws the dependency tree. The arrow direction and labels are generated by the spaCy model.

## 5. Project workflow
1. User enters English text.
2. spaCy tokenizes the text.
3. The model predicts lemmas, POS tags, morphology, and syntactic dependencies.
4. The application builds a table for each token.
5. displaCy renders the dependency tree.
6. The user can download the token analysis as CSV.

## 6. Suggested objectives
1. To implement an NLP-based sentence analyzer for English text.
2. To identify tokens, lemmas, stems, POS tags, and morphological features.
3. To identify syntactic dependencies such as subject, object, and determiner.
4. To visualize sentence structure using a dependency tree.
5. To evaluate the output on simple, compound, and complex sentences.

## 7. Limitations
- This is a rule/model-assisted analysis using a pretrained model, not a newly trained parser.
- The default model is for English.
- Predictions may fail on slang, misspellings, ambiguous sentences, and specialized text.
- Stemming is a crude word reduction method; it is not the same as lemmatization.
- Dependency labels can differ across annotation schemes and model versions.
